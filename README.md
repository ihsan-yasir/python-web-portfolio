# Python Web Portfolio

By [ihsan-yasir](https://github.com/ihsan-yasir) · [Guru-ready project descriptions](GURU_PORTFOLIO.md)

Three working, independently launchable sample projects built with **Python 3.10+ and SQLite**, using only the Python standard library. All application logic is Python. HTML and CSS are generated by Python; no JavaScript, frameworks, CDN assets or package installation are needed.

These are fictional, AI-assisted portfolio projects, not client commissions. The implementations interpret the earlier concept designs. The previous concept images are not screenshots of these applications. Automated functional tests pass. Browser visual verification and actual application screenshots are not yet included.

## Run

Install Python 3.10 or newer, download this repository and open a terminal in its folder.

```sh
python app.py
```

Open **http://127.0.0.1:8000**. Use the navigation to switch projects.

Or launch each separately:

| Project | Command | Address |
|---|---|---|
| Northline business website | `python business_website.py` | http://127.0.0.1:8001 |
| Forma online store | `python online_store.py` | http://127.0.0.1:8002 |
| Taskboard dashboard | `python management_dashboard.py` | http://127.0.0.1:8003 |

On Windows, `py` can replace `python`. Stop with Ctrl+C. Use `--port 8080` to choose another port, or `--database path/to/demo.db` to choose another database.

## 01 · Northline

A responsive consulting business website with service cards, abstract architectural artwork, navigation and a validated contact form. Enquiries are saved in SQLite. The confirmation accurately indicates that no email is sent.

## 02 · Forma

A searchable four-product homeware catalogue, session-specific shopping bag, quantity editing, removal and simulated checkout. Order totals are calculated server-side using integer cents. Orders and line items persist in SQLite. No payment processing, shipping, tax or stock management is connected.

## 03 · Taskboard

A persistent project dashboard with task creation, status updates, deletion, text search and status filtering. Summary cards show total, in-progress, completed and overdue tasks; the completion bar is calculated from stored tasks. First-run seed data is not re-created after tasks are deleted.

## Data and scope

The database is created under `data/`, excluded from Git. Tasks are shared within the local demo. Enquiries and orders persist across restarts; browser sessions and carts are in memory and reset when the process restarts. Use fictional information.

The server binds only to the local computer. This is a local portfolio demo, not a production commerce or multi-user service. Public deployment would require production hosting, authentication, permissions, HTTPS, durable sessions, abuse controls and operational review. GitHub hosts the source code; uploading this repository does not run the Python applications. GitHub Pages cannot execute this server.

## Verification

```sh
python -m unittest discover -s tests -v
```

Tests cover persisted enquiries, validation, CSRF protection, isolated carts, quantity validation, order totals, empty checkout, task lifecycle, escaped content, persistence and project isolation.
